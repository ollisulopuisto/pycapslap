# Finnish proofreading in Tekstitys

Owner request: integrate Voikko/Punakynä; build go on 2026-11-11.
Status: implementation for a draft PR, not merged or released.

- Vendor the exact MIT engine source at pyside/punakyna/UPSTREAM_COMMIT.
  Upstream explicitly disables installable packages, so a git dependency does
  not install the engine. No private corpus or model weights are copied.
- Check cue text with its immediate neighbours, rejoin explicit syllable splits,
  and map only wholly contained findings back to a cue. Cross-cue corrections
  are omitted rather than silently changing cue boundaries or timing.
- Default Errors: spelling and grammar errors/warnings. Style and informational
  suggestions are opt-in with Errors + style (active-voice and long-sentence
  advice; no narrator/reader person is guessed). Off loads no native library.
- Debounced single-flight worker. Painting reads cached immutable results only;
  edits clear stale spans and invalidate earlier generations. Suggestions
  never apply automatically. Applying a menu action rechecks its original text.
- Qt UTF-16 layout positions are converted to/from Python code points when
  painting findings and matching a right-click.
- Bundle native dependencies and dictionary with licence texts; ship matching
  source archives alongside the app inside the DMG. See scripts/voikko/README.md.

## Validation and remaining gates

Targeted unit/Qt and isolated Linux native engine tests run locally. The preview
is a real offscreen Qt render with actual engine results, not a Mac screenshot.
CI includes a small frozen Mac engine smoke; release checks run the actual signed
GUI executable with --proofreading-smoke. Signed/notarized Mac delivery remains
unverified until that workflow runs. Colloquial-transcript precision is not
benchmarked; an Errors-only default is not a guarantee of no false positives.

The repository lacks a top-level licence. Combined GPL distribution licensing
must be settled before publishing a release. This work does not choose or grant
that licence. Human merge and release approval remain required.
